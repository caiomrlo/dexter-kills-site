# Dexter Kills

![Dexter Kills landing page preview](docs/preview.webp)

A cinematic, scroll-driven landing page inspired by *Dexter*.

**Live demo:** <https://caiomrlo.github.io/dexter-kills-site/>

## About

This is a fan project. I built it out of love for the series, and also as a hands-on way to practice 3D rendering on the web. The page mixes atmospheric imagery, bold typography and scroll-triggered animation, with 3D elements running in the browser.

It's not affiliated with or endorsed by the creators or owners of *Dexter*. All characters, images and related media belong to their respective rights holders.

## Built with

- HTML, CSS and JavaScript
- [Three.js](https://threejs.org/) for 3D rendering
- [GSAP](https://gsap.com/) + ScrollTrigger for scroll animation

## Running locally

```bash
npm start
```

Then open <http://localhost:8123>. The page live-reloads on file changes.
